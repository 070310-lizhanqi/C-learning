一、复合语句(大括号{})
{}内是一块独立的小空间
-->括号内的是内层变量，括号外的是外层变量
-->!!!内外层变量同名时，内层优先，互不干扰!!!


二、字符串输入/输出
1、putchar-->输出单个字符
可输出的参数：字符常量、转义字符、ASCII 码整数
用法示例：
    putchar(97);   // 97是'a'的ASCII码，输出a
    putchar('a');  // 直接写字符常量，输出a
    putchar('\n'); // 转义字符，换行
2、getchar-->从键盘读取一个字符
getchar()读到的是ASCII码值,所以可以用int变量存，也可以用char
输入完必须按回车，程序才接受
一次只能读取1个字符
用法示例：
    int ch;
    ch = getchar();  // 键盘敲一个字符，回车确认，把这个字符的ASCII码放到ch
    putchar(ch);

-->跟printf的区别是putchar和getchar两个函数只能处理单个字符,而printf可以输出一串字符串


三、格式化输出
1、printf("格式控制字符串"，输出项列表)
-->普通字符+格式占位符+转义字符
-->格式占位符
    %d:十进制整数
    %o:八进制整数
    %x:十六进制小写/%X：十六进制大写
    %u:十六进制无符号整数
    %c:输出单个字符
    %s:输出字符串
    %f:输出浮点数
    %p:输出指针
    -->进阶占位符
        %[标志+宽度+.精度]类型
        %5d：占 5 个字符宽度，不够左边补空格，默认!!!右对齐!!!
        %-5d：-代表!!!左对齐!!!，右边补空格
        %8.2f：总共占 8 位，小数点后保留 2 位
    例子：printf("%8.2f", 3.1415);  输出：00003.14
2、scanf("格式控制字符串",地址列表)
-->能写宽度，但不能写精度
